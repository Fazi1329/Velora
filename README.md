VELORA is an independent online product-sourcing and disclosed purchasing-agent business connecting international clients with products from its supplier network through a personalized WhatsApp concierge experience.

## Official Business Details
- **Brand**: VELORA
- **Official WhatsApp**: [+966 57 316 4981](https://wa.me/966573164981)
- **Business Model**: Disclosed Purchasing Agent
- **Brand Identity**: Royal Purple (`#5426A8`), Deep Purple (`#32145E`), Soft Lavender (`#F0E9FF`), Gallery White (`#FFFFFF`)
- **Ordering Method**: Online catalogue with personal WhatsApp order confirmation
- **Payment Methods**: PayPal & Institutional Bank Wire Transfer

## Features
- **5-Stage Cinematic Editorial Scroll**: Built with CSS custom properties and generative silk linework canvas.
- **55-Product Supplier Catalogue**: Sourced from official supplier price lists with preserved prices and verified specifications across Electronics & Audio, Sportswear & Athleisure, Hoodies, Luxury & Designer Brands, and Haute Colognes.
- **Supplier OCR Verification Desk**: Side-by-side verification screen comparing extracted product lots against original supplier images.
- **Dynamic WhatsApp Pre-fill**: Automatic message generation containing product title, SKU, price, and current link for seamless customer verification.
- **Configurable Payment Desk**: Editable settings for official PayPal links and institutional bank wire instructions.

## Getting Started
To view locally, simply open `index.html` in any web browser or serve via any static web server:

```bash
python -m http.server 8080
```
Then navigate to `http://localhost:8080`.
